# Date Fruit Classification

*Machine Learning-Based Date Fruit Classification | Makine Öğrenmesi ile Hurma Sınıflandırması*

**About | Hakkında**

**EN:** A machine learning project focused on classifying different date fruit varieties through data analysis and classification algorithms.

**TR:** Veri analizi ve sınıflandırma algoritmaları kullanılarak farklı hurma çeşitlerinin sınıflandırılmasını amaçlayan bir makine öğrenmesi projesidir.

**Objectives | Amaçlar**

- Exploratory Data Analysis | Keşifsel Veri Analizi
- Data Preprocessing | Veri Ön İşleme
- Classification Algorithms | Sınıflandırma Algoritmaları
- Model Evaluation | Model Değerlendirme

**Algorithms | Algoritmalar**

- K-Nearest Neighbors (KNN)
- Decision Tree
- Random Forest
- Support Vector Machine (SVM)
- Naive Bayes
- Logistic Regression

**Technologies | Teknolojiler**

`Python` `NumPy` `Pandas` `Matplotlib` `Scikit-learn`

**Project Status | Proje Durumu**

In Progress | Geliştirme Aşamasında
